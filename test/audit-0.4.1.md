# 0.4.1 功能与按钮复核

日期：2026-10-13。Google Chrome，原版 ZCode 网页、官方中继、隔离的真实 DSH Host。
手机尺寸 390x844，宽屏 1440x960。模型使用确定性回放，不是付费模型或 iPhone/Safari 实机测试。

最终回归：单测 66 项；Chrome `--flows --audit`、`--features`、`--extended`、严格 `--history` 通过，未捕获网页异常为零。
未支持的功能仍在下面单独列明，不宣称全功能一致。

## 已修复

| 问题 | 修复与证据 |
| --- | --- |
| 停止新回复使历史成功回复显示“已停止” | 保留各轮开始/结束事件；Chrome 断言三轮完成、一轮停止 |
| 旧工具调用被新一轮错误标为运行中 | 按各轮结束状态结算；单测 |
| 目标继续回复混入上一用户轮次 | 独立轮次及目标来源；单测 |
| 快照重同步保留旧流式文字、旧 attempt 干扰新回复 | 清理快照流状态，匹配 attempt ID；单测 |
| 更多菜单重命名接口未接线 | 对接 renameTask，返回真实任务元数据；Chrome 取消/确认并核对 Host |
| 三档主题切换产生未处理异常 | 仅转发网页主题广播，不修改 DSH 设置；单测与 Chrome |
| 设置页网络恢复后仍保留旧错误 | 区分轮询错误和操作错误；Chrome 注入 503 后恢复 |
| 置顶/归档接口返回空对象、元数据固定只读 | 返回真实任务元数据；会话、设置、投影和任务元数据统一实际权限；单测与 Chrome 回归 |
| 桌面改名后手机标题栏保留旧值 | 补充原版 shell 支持的外部任务元数据广播，使用标题事件时间；严格历史及置顶改名 Chrome 验证 |
| 放弃新建空草稿遗留在活动列表 | 仅归档本次远程创建且未使用/改名/置顶的空会话；Chrome 核对可恢复且不影响已有空会话 |

## 未解决与验证边界

1. **草稿清理语义差异：** DSH 没有公开会话删除 API，因此映射为可恢复归档；不操作文件，不永久删除。断网或退出导致清理请求未送达时仍可能留下空会话。
2. **标题兼容依赖：** 原版 shell 与 v4 正文使用不同缓存，适配器通过现有 `bots:task` 元数据通知同步（不创建机器人、不发送 prompt）；未来上游协议变化仍可能影响兼容性。
3. **P2/P3：可见但未适配的控件。** 见清单；这不是“全部按钮测试通过”。原版网页不由插件托管，不能仅靠当前协议能力隐藏所有入口。
4. 上游 Tooltip controlled/uncontrolled 警告仍存在。一次图片回归出现资源加载警告，重新执行图片移除/重加/预览/刷新后没有复现；不宣称覆盖所有网络时序。
5. 未验证 Safari 后台挂起、多手机竞争、所有文件格式、付费模型实际响应或任意网络故障。
